**The one model change: documents by TYPE.**
- The prototype's rows are the person's documents by type. SS-07 listed uploaded files instead.
- Rows now follow DS-07's staff-side rule: **iqama · work permit · employment contract · passport**, each dated from the **record**. When the record has no date, the matching file's own expiry is used.
- **Download** appears where an available file of a matching category exists; the one valid longest is used.
- A Saudi gets no iqama or work permit row.
- **Uploaded files that match no type keep a row of their own**, so nothing an employee could download before is lost.
- The chip is People's scale: red ≤7 days, amber ≤14, grey ≤30, faded later.

**Kept beyond the prototype:**
- **Download** on each row: the prototype has none, ours had it, and the card kept it.
- GOSI registration status and the exit/re-entry status · date, as identifier lines.
- IBAN still shown as `•••• last 4` (SS-03).
