## Three deviations from the system, each measured

### 1 · Geist, but only with Arabic composed behind it

The system sets headings in Geist. Geist has **no Arabic glyphs**, and loading it the
obvious way (`geist.className`) replaces the whole family — on the Today preview that
put Arabic in "Geist Fallback", a metric-adjusted Arial. So Geist gets Inter's
treatment: a variable only, `adjustFontFallback: false`, composed as
`--font-display, --font-arabic, …`.

```
h1 stack   Geist, "IBM Plex Sans Arabic", "IBM Plex Sans Arabic Fallback", ui-sans-serif, …
Latin  h1  432.20px  = Geist 432.20    (Inter would be 442.16)
Arabic h1  794.02px  = Plex  794.02    (Arial would be 630.28)
body text  still Inter                 tracking −0.24px = −0.01em at 24px, as specified
```

Only `h1` takes the display face. Card and section titles stay **Inter Medium** — the
system's own correction ("the kit sets titles in Inter Medium rather than Geist").

### 2 · The soft badge's shape, not its colours

The system's signature soft badge — label in the status hue on a 10% tint of itself —
**fails WCAG AA in all four tones** for 12px text:

```
info     3.62:1  FAIL      error    4.13:1  FAIL
success  2.96:1  FAIL      warning  2.86:1  FAIL
```

StatusPill takes the shape (full radius, tint, no outline) and keeps our deep tones,
which pass on the same tint: critical 7.81 · warning 6.13 · ok 5.62 · info 6.32 ·
neutral 5.48 (`node apps/web/scripts/verify-status-contrast.mjs`, extended in this card
to report the system's as-designed values alongside ours).

### 3 · A pre-existing AA failure, surfaced and fixed

The extended script added the core roles, and one failed:

```
muted-foreground (.556) on muted surface (.97)   4.34:1  FAIL
```

That is the system's pair verbatim — **and was ours before this card too**, so it is
pre-existing, not introduced. `.546` is the first value clearing 4.5:1 on white,
sidebar and muted; `.54` leaves headroom:

```
muted-foreground on background   5.06:1   on sidebar 4.85:1   on muted 4.64:1   all PASS
primary-foreground on primary   17.16:1   (button text)
```

## What stays deliberately

- **The PEOPLE&GRO mark and the login panel** keep their sampled navy and gold — they
  are brand artwork, not interface chrome, and use constants rather than `--primary`.
  Measured: login panel still `rgb(4, 10, 49)`.
- **No dark mode** — the system ships dark tokens; we still do not.
- **Logical properties only** — the prototype has 88 physical properties and 0 logical;
  none came across.
