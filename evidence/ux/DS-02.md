## Source

The shell markup of `People & Gro Console.dc.html` (the readable, untruncated head of
the prototype): a 248px sidebar with a 56px brand row, uppercase group labels, 36px
rows with count pills, a pinned foot (Settings + identity + sign-out icon), and a 56px
header whose left side is a location line.

## Owner decisions with this card (approved with the card)

| # | Decision | Effect |
|---|---|---|
| 1 | **Keep font-weight on the active nav row** | Deviation from the system (it marks the active row by fill alone). UX-11 made the weight the non-colour cue (WCAG 1.4.1); it stays. |
| 2 | **Nav counts for open Requests and my open Tasks** | Existing endpoints, fetched once per app load, permission-gated, silent failure. |
| 3 | **Follow the design's location line** | **Reverses the UI/UX epic's "no breadcrumbs" decision.** Recorded in `header-location.tsx`: the NN/g reasoning still holds for *navigation* (the hierarchy is ≤2 deep); what ships is a *location line* that names where you are and, on a record, carries its name. Only the screen crumb links. |

Excluded (unchanged from the card): global search, saved views, "viewing as", nav
regrouping (comes with the screen cards), notification-panel redesign.

### Sweep — 14 staff screens × 2 locales × 2 widths = 56

Each screen loaded in a same-origin iframe sized to the viewport (each frame is its own
media-query viewport). Columns: overflow px · visible `aria-current` · visible `h1` · crumb.

- **en 1280:** all 14 → `0 | 1 | 1 | PEOPLE&GRO / <Screen>`
- **ar 1280:** all 14 → `0 | 1 | 1 | PEOPLE&GRO / <الشاشة>` (e.g. `PEOPLE&GRO / الجوازات`)
- **en 375 / ar 375:** all 14 → `0 | 0 | 1 | <Screen>` — the product name yields on a
  phone; `aria-current` is 0 visible because the sidebar is `md:flex` and the sheet is

### Sign-out

- **Sheet, by mouse click at 375 (ar):** → `/ar/login`, `/auth/me` → **401** (server session revoked).
- **Sidebar at 1280 (en):** the button is visible; the emulated 1280 viewport is scaled to
  fit a 598px pane, which makes coordinate clicks drift (an earlier click aimed at Employees
  landed on GRO), so it was activated by `element.click()` → `/en/login`, `/auth/me` → **401**.
  Same component and handler as the sheet's mouse-verified button.

### Mobile sheet

First measurement: sign-out at **y=937 in an 812px sheet** — the whole popup scrolled, so
the one place sign-out lives on a phone needed a scroll to reach. Fixed by making the
popup `overflow-hidden` and the nav `min-h-0 overflow-y-auto`, the same arrangement as the
desktop sidebar. After: sign-out bottom **800 of 812**, nav scrolls (765/628), popup does
not (812/812). Rows **44px** (13 of 13), sign-out **44×44**, one visible `aria-current`, 0px
page overflow; the log-out glyph is mirrored in RTL (`rtl:-scale-x-100`).

### Defect caught by measuring

**Two `aria-current="page"` per screen** on the first sweep: the nav row AND the current
crumb. UX-11 established exactly one; the current crumb is plain text (not a link), so the
attribute was removed from it. Re-swept: one.
