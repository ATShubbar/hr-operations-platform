## What shipped

The single centred card becomes two columns: the form on the start side, the brand panel
on the end side from `lg` up. `grid-cols-2` rather than two positioned halves, so **RTL
mirrors it for free** — verified, the panel lands on the left in Arabic with no extra CSS.

The block was **not** taken as-is. Three of its elements have no counterpart here:

| login-02 | Here |
|---|---|
| "Forgot your password?" | no reset flow exists |
| "Or continue with" + GitHub | no OAuth |
| "Don't have an account? Sign up" | accounts are created by a System Admin (UX-10b) |

All three are replaced by one line — *Accounts are created by an administrator* — shown on
the **credentials step only**, since by the MFA steps you have already proven you have one.

The block's `field` dependency was also not installed: we standardised on `<Label htmlFor>`
in UX-13, and a second labelling primitive would have arrived for no gain.

## Below `lg`, the panel is hidden, not stacked

It carries identity, not information, and a phone should reach the password field without
scrolling past a photograph. Measured at 375px:

```
panel display: none      submit button bottom: 508 of 760   (in view, no scrolling)
page overflow: 0px       vertical scroll: 0px               exactly one <h1>
```

## The image fit, carried over from the preview

The artwork is 1.79:1 and the column is ~0.84:1, so `object-cover` can only ever show
about **46% of the source width** — and the skyline is in its left half while the wordmark
is in its right, so the two cannot both survive the crop.

The asset is pre-cropped to the skyline at **1130×1340 (0.843)**, near-identical to the
column, which also removes the baked wordmark permanently at any panel shape. The name and
slogan are drawn on top: sharp at any density, and translatable.

`BRAND_NAVY` / `BRAND_GOLD` are sampled from the artwork rather than approximated — the
panel's ground has to match the photograph's own sky or the seam shows, and the rule has
to be the mark's gold, which is not our `--primary`.

## A duplication caught on first render

The slogan printed **twice on one screen** — as the form's subtitle and again on the
panel — and in the narrow form column it wrapped over two lines, where a tagline never
belonged. `auth.signInSubtitle` (set to the slogan in UX-15, when there was no panel to
carry it) is now a functional prompt, and the slogan moved to its own key:

```
auth.slogan          Your Partner in HR Operations & Talent Solutions
auth.signInSubtitle  Enter your email and password to continue.
```

## Verified — including a real sign-in

The page was restructured around a working auth flow, so the flow itself was exercised,
not just the layout:

| | |
|---|---|
| **real credentials sign-in** | `staff-hr_officer` → landed on `/ar/today` — the AUTH-08 stored-language redirect still honoured |
| **MFA enroll step** | reached with `staff-company_admin`: heading, 32-char setup key, code field, verify button, 1 `h1`, 0px overflow |
| Arabic | panel on the start edge, setup key still LTR inside an RTL column |
| 375px | panel hidden, submit in view, 0px overflow |

**No state was mutated to test MFA.** `/auth/mfa/enroll` writes the pending secret to the
Redis session only — `auth_users.mfa_secret` is set at *verify*, never at enroll. Confirmed
after the run: **9 users, 0 enrolled**, unchanged.

## Landmine

`npx prettier --write` from the repo root does **not** pick up the shared config
(`packages/config/prettier.config.mjs` is referenced by each package, not by a root
`.prettierrc`). It reformatted the whole file to double quotes against the project's
`singleQuote: true`. Re-run with `--config packages/config/prettier.config.mjs`.
