### Field mapping — nothing the old page showed is lost

The prototype's fields come first, in its order. The record's other stored fields follow in the
section they belong to.

| Section | The prototype's fields | Also kept (stored, not in the prototype) |
|---|---|---|
| Identity | Full name · Name in Arabic · Nationality · Iqama number (**National ID for a Saudi**) · Border number · Passport number · Passport expiry | Iqama expiry (non-Saudi) · the other identifier when one is on file · Gender · Date of birth |
| Employment | Position · Department · Client company (read-only, "Moving employer is a sponsorship transfer, not an edit.") · Joined · Contract ends · **Qiwa contract — "—", "Not stored yet."** · GOSI number | Position in Arabic · Contract type · Employment status · Counts toward Saudization · Work permit number + expiry (non-Saudi) · GOSI registration · Absher reference · Exit re-entry + expiry (non-Saudi) |
| Compensation ("Monthly, in SAR.") | Basic salary · Housing allowance · Transport allowance · IBAN | Other allowances · GOSI wage · GOSI contribution basis · WPS status · Currency |

**Editable now that weren't before:** date of birth and "Counts toward Saudization". The
update API always accepted both; the old dialog didn't offer them.

**Deliberately kept editable** although the prototype marks them read-only: passport expiry,
joined date and contract end. The prototype changes passport expiry and contract end by
recording a renewal on Documents, which arrives in DS-07; removing the only way to change them
now would lose a capability.

## Bugs caught while verifying

- **The record page bundle went 9.6 kB → 41.9 kB.** The procedure dialog imported
  `groProcessTypeSchema`, a zod VALUE, so all of zod shipped to the browser. The dialog now uses
  a local list checked with `satisfies readonly GroProcessType[]`. **18.4 kB after**; the
  remaining growth is the Tabs primitive and the profile logic.
- **"GRO officer can read this section but not change it"** appeared on Compensation, which the
  GRO officer cannot read at all. The prototype shows the line regardless. It now shows only
  when the section has something readable; the masks already say "hidden".
- **Tab panels were focusable with no visible focus** (`outline-none` on a Base UI panel, which
  is a tab stop). They now keep a focus outline.
